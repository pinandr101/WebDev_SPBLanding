# СПБ Landing

СПБ Landing - отличный выбор для каждого туриста, планирующего посетить культурную столицу России. Этот веб-сайт позволит выбрать точки интереса на каждый день пребывания в городе. Для облегчения выбора на сайте представлен поисковик, а также удобная сортировка по адресам.

## Описание

Целью данного проекта являлось освоение принципов работы с React: дробление сайта на мелкие компоненты, с которыми удобно работать, использование таких хуков как UseState, UseContext и UseEffect.

Вся информация, представленная на сайте является выдуманной/недействительной/взятой из открытого доступа.

Проект был создан в качестве домашнего задания для курсов дополнительного образования от IT-академии Samsung по фуллстек разработке.

## Установка
Для того, чтобы запустить проект на своём вычислительном устройстве необходимо: 
1. Клонировать репозиторий на устройство
2. Установить зависимости с помощью следующей команды в консоли, находясь в корне проекта:
```bash
npm install
```
3. Запустить локальный сервер:
```bash
npm run dev
```
4. Проект готов к использованию по ссылке, выведенной в консоль
